The Task

"Activate users"

A user record existing isn't the same as a user being able to log in. Activation is the step that turns "exists in Okta" into "can actually sign in and use assigned apps."

The Mechanism — Two Methods

Individual — open the user's profile page, click Activate.

Bulk — from Directory > People, select users, More Actions > Activate, choosing to activate all or specific selected accounts.

The Mechanism — What Activation Does

Activation triggers an email notification to the user's primary or secondary address, confirming the account is active and including setup instructions.

Once activated, the user can access all provisioned applications already assigned to them — activation doesn't assign new apps, it unlocks access to what's already there.

The Gotcha — Status Matters for the Path

Staged accounts activate directly from the Status column in Directory > People.

Suspended or deactivated accounts require going into the user's profile page instead — the Status-column shortcut doesn't work for them.

The Gotcha — Bulk Activation Visibility

Bulk activation requires selecting "Show deactivated users" before proceeding.

If that toggle isn't on, deactivated accounts simply won't appear in the list to select for bulk activation — an easy thing to miss mid-task.

The Angle — What Trips People Up

Watch for these in your own sandbox run:

→ Trying to activate a suspended user from the Status column shortcut — it won't work; go to their profile page.

→ Not seeing a deactivated user in a bulk list — check "Show deactivated users" first.

→ Expecting activation to grant new app access — it only unlocks apps already assigned, it doesn't assign anything new.

One Line To Remember

Activate individually (profile page) or in bulk (More Actions > Activate, with "Show deactivated users" on if needed). Activation emails the user and unlocks already-assigned apps. Staged accounts activate via the Status column; suspended/deactivated accounts need the profile page instead.
